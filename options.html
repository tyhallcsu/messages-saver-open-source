Open Chat Archiver

Settings for local conversation export. All settings stay on this device.

Default export format

Filename template

Tokens: {thread}, {date}, {time}, {count}, {ext}.

Capture behavior

When enabled, the extension will gently scroll the message list upward to load older messages. Manual scrolling always works regardless.

Privacy

  • Everything runs locally in your browser. No remote servers are contacted by this extension.
  • The extension only reads what is already rendered in your own DOM — it does not call private APIs.
  • Exports are saved through the browser's standard Downloads API.

See the PRIVACY.md file in the source repository for full details.
