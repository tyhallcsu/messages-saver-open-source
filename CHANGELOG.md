# Changelog

All notable changes to Open Chat Archiver will be documented here.

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/),
and this project follows [SemVer](https://semver.org/).

## [Unreleased]

## [0.1.2] — 2026-05-01

### Added
- README "How it works" section now includes
  `assets/overview.svg` — the popup-flow / export-output illustrative
  diagram. Sits alongside the live-capture screenshot in the Preview
  section (both retained per maintainer request).

### Changed
- `popup.html` and `options.html`: footer link text changed from the
  generic words "Source" / "Source code" to the actual repo URL
  (`github.com/tyhallcsu/messages-saver-open-source`). The link
  destination is unchanged. Makes the popup unambiguous about where
  the link goes.
- `popup.js → wireRepoLink` and `options.js → wireExternalLinks` now
  also rewrite the link's `textContent` and `title` attribute from
  `manifest.homepage_url` (with the URL scheme stripped for display).
  This keeps the link text and href in sync if the manifest's
  homepage_url is ever changed in a future release.

## [0.1.1] — 2026-05-01

### Added
- `.github/CODEOWNERS` routing every path to the maintainer (@tyhallcsu).
- Reusable `_validate.yml` workflow shared by CI and release; both run
  the same gate over every push and tag.
- Auto-release pipeline: `release.yml` triggers on any of three paths —
  `manifest.json` version bump on `main`, tag push matching `v*.*.*`,
  or Actions-tab `workflow_dispatch` — and gates publication on the
  validate workflow passing. Publishes a populated GitHub Release with
  zip, SHA-256, file manifest, and an install / verify / usage body.
- `node --check` over every extension JS file in CI.
- Manifest path-existence test in CI: every icon / script / popup /
  options / content-script / web-accessible-resource path declared in
  `manifest.json` must exist on disk.
- Sample-data schema test verifying the documented JSON contract
  (`schema`, `messageCount` parity, required keys, `direction` enum).
- `homepage_url` in `manifest.json`; `popup.js` and `options.js` read
  it at `DOMContentLoaded` and rewrite their Source / Privacy links
  to match instead of hardcoding URLs in HTML.
- Self-contained HTML sample at `sample-data/sample-conversation.html`
  to accompany the existing JSON / CSV / TXT samples.
- `AGENTS.md` Codex counterpart to `CLAUDE.md` with the same hard
  rules and file map.
- `assets/hero.svg`, `assets/overview.svg`, and
  `assets/messages-saver-screenshot.png` for README presentation.
  README's Preview section uses the live-capture screenshot.

### Changed
- Redesigned PNG icons (16 / 48 / 128 px) — blue rounded tile with a
  white chat-bubble download glyph. Generated by stdlib-only
  `scripts/generate_icons.py`; CI's icons-diff check still passes.
- `content.js` capture lifecycle refactored: `watchUrl` is now
  `start/stopUrlWatcher` with a tracked `setInterval` handle. Fixes a
  leak where each Start/Stop cycle accumulated a forever-running
  interval. Re-anchors `lastKnownUrl` on start and bails out of the
  SPA-switch path when capture is off.
- README polished with hero, scoped badges, at-a-glance table,
  per-format sample table, How it works section, and a Preview
  section showing the popup mid-capture against a real Messenger
  thread. Every claim sourced from `manifest.json`, `CLAUDE.md`, or
  source files.
- `docs/USAGE.md` rewritten as a complete end-user walkthrough: TOC,
  install paths (clone or release zip), Options reference table,
  popup status-dot legend, date-filter edge cases, format selection,
  export verification (completeness / ordering / fidelity / privacy
  audit), update procedure, and expanded troubleshooting.
- `CONTRIBUTING.md` documents the day-2 PR-based workflow, pre-merge
  checklist, release-tagging procedure, and current
  branch-protection status.
- CI disallowed-network-API grep now also rejects `EventSource` and
  `importScripts`.

## [0.1.0] — initial public release

### Added
- Manifest V3 Chrome extension scaffolding.
- DOM-based conversation capture via `MutationObserver` on the active
  Messenger / Facebook conversation region.
- Popup UI with status indicator, live capture count, date-range filter,
  format picker, and export button.
- Options page with default format, filename template, scroll pacing,
  capture toggles (reactions, attachment URLs, consecutive collapsing).
- Background service worker with JSON / CSV / TXT / HTML serializers,
  filename templating, and `chrome.downloads.download()` integration.
- Original PNG icons at 16, 48, and 128 px, generated from
  `scripts/generate_icons.py` with standard-library Python only.
- Sample synthetic exports in `sample-data/`.
- Documentation: README, PRIVACY, ARCHITECTURE, USAGE.
